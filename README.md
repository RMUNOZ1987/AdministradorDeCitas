Administrador de Citas
Descripción

Este proyecto consiste en una aplicación desarrollada en Java que simula un sistema básico de administración de citas para un consultorio clínico.
El sistema permite registrar doctores, pacientes y crear citas, relacionando a cada doctor con un paciente en una fecha y hora específicas.
El proyecto fue desarrollado como parte de una actividad académica para practicar programación orientada a objetos y el uso de control de versiones con Git y GitHub.

Instalación y configuración
Java JDK 8 o superior
IntelliJ IDEA (u otro IDE compatible con Java)
Git

Pasos para ejecutar el proyecto
Clonar el repositorio:
git clone https://github.com/TU_USUARIO/AdministradorDeCitas.git
Abrir el proyecto en IntelliJ IDEA.
Verificar que el proyecto compile correctamente.
Ejecutar la clase AdministradorDeCitas.
Al iniciar el programa, si no existen los archivos de datos, el sistema creará automáticamente la carpeta db y los archivos necesarios.

Uso del programa

Al ejecutar el programa se mostrará un menú con las siguientes opciones:
Agregar doctor
Agregar paciente
Crear cita
Mostrar doctores
Mostrar pacientes
Mostrar citas
Salir
El usuario interactúa mediante la consola ingresando los datos solicitados en cada opción.
